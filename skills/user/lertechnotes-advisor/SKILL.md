## Audience

- **IT diploma/degree students** in Malaysia/SEA learning to use AI tools
- **HRDC workshop participants** exploring Claude, n8n, automation
- **Solopreneur developers** running lean stacks (n8n, Claude, WordPress, VPS)
- **Tech educators** integrating AI into teaching and assessment
- **Side-project builders** doing more with less (zero/low-cost AI stack)

They are NOT:
- Enterprise architects
- Western Silicon Valley audience
- Absolute beginners with no coding exposure
- Chinese metaphysics readers (that's Ler Destiny Notes)

## Content Sweet Spots (High Score = Fits These)

1. **"Here's what I actually built and what happened"**
   — Real implementation stories beat tutorials. Show the messy parts.

2. **Claude Code patterns** — slash commands, SKILL.md files, hooks, harness
   engineering, agents. LerLer is building this actively; readers follow along.

3. **n8n workflow designs** — automation that solves a real single problem.
   Concrete node sequences, not vague overviews.

4. **AI tools comparison with honest SEA context**
   — e.g. "OpenRouter vs direct Anthropic API for Malaysian devs on a budget"

5. **Low-cost/zero-cost AI stack for solo builders**
   — Ollama, free tiers, self-hosted alternatives, Tailscale tricks.

6. **Teaching AI to non-technical people** — workshop lessons, what confused
   students, what clicked, what to do differently.

7. **WordPress + AI integrations** — plugin dev, automation, REST API tricks
   relevant to WordPress practitioners.

---

## Avoid (Low Score / Skip)

- Pure theory with no implementation detail
- Topics already covered to death in Western AI newsletters (e.g. "what is RAG")
- Anything requiring a $100+/month stack (not the audience)
- Metaphysics content (BaZi, Qimen, Ziwei) → belongs in Ler Destiny Notes
- Travel content → belongs in lertraveldiary.com
- Generic "AI will change everything" thought leadership

---

## Voice Guidelines for Hook Paragraph

- First person ("I spent 3 hours debugging this before I realised...")
- Start mid-action or with a specific problem, not a definition
- Malaysian/SEA context is fine and welcome ("On my K45VD setup...")
- Short sentences preferred. Vary length for rhythm.
- No AI-isms: no "In today's rapidly evolving landscape", no "game-changer",
  no "It's worth noting that", no "Dive into"
- Reads like a WhatsApp message from a knowledgeable friend, but written
